Technical architecture for the public pilot

Three small modules, no database, no CMS, no live AI.

Module 1

Approved content

Markdown narratives, small structured records, glossary, citations, and explicitly approved assets.

Human-editable and versioned in Git.

Module 2

Validator / exporter

Checks schemas, links, locators, labels, asset rights, and the publication allowlist; emits one clean reader bundle.

No raw-repository mirroring.

Module 3

Static reader app

Astro-style content site with search, filters, backlinks, tooltips, optional graph, and source/audit drawers.

Quartz-inspired, not Quartz-coupled.
Build and delivery flow

Research workspace → human approval → approved content

↓

Preflight validator → errors stop build; warnings require review

↓

Static build → generated search index + relationship data + allowed PDFs

↓

Local preview → scientific, rights, accessibility, and reader review

↓ explicit operator approval

Public static deployment → readers browse; corrections return to the repository workflow

Public means public

GitHub Pages is viable again

Every generated page, JSON file, search index, relationship record, and locally hosted PDF can be fetched by anyone. An unlisted URL is not private.

The exporter therefore includes only explicitly approved records and redistribution-cleared assets. Everything else stays in the research workspace.

Later migration: an access layer or individual accounts can be added without changing the content model.

Build errors

Missing required record · broken internal relation · mixed evidence label · forbidden path · local PDF without rights · missing audit locator.

Result: no publish bundle.

Runtime handling

Missing source → retain citation and report unavailable link. Missing page → safe 404 with navigation. No secrets or private paths may enter the bundle.

No scientific state changes in the browser.

Minimal operations

One content repository · one deterministic build · one public static deployment · no application database · no background worker.

This is the Chisle/YAGNI boundary.
