# Start here: portable AI research handoff

Permanent bootstrap: "Read START_HERE.md and perform the next eligible task."
Use that same message in any working research chat or agent. No Computer/Council credits, API router, or special harness is required by this protocol. Platform access/limits still apply; files cannot trigger execution by themselves.

1. Read AGENTS.md, charter.md, and state/work-queue.yaml.
2. Select the first queued task whose dependencies are complete_bounded. Check existing outputs to avoid repeating completed work. Read only its inputs and relevant sources, not every historical chat/log.
3. Do one task. Choose searches, languages, calculations, and hypotheses within scope. Try an authorized alternative once if a tool fails; record blockers rather than repeatedly retrying quota/DSML failures.
4. Save/read back outputs; update the selected queue item and append a dated session-log entry in your proposed patch. Artifact completion is not scientific validation.
5. Show the diff/output bundle for human review. Respect host approvals for commits/PRs. Stop; the next session uses the queue without needing a new custom prompt.

Without GitHub access, request the control files and selected inputs once as attachments. Return Markdown plus proposed queue/log edits; never claim repository persistence. If all tasks are complete/blocked, propose specific next tasks with reasons, not an endless goal.

Use one writer at a time. Preserve uncommitted human changes. Ask only for genuinely missing access/inputs, conflicting material requirements, spending, irreversible writes, or experimental decisions. Do not ask "what next?" when the queue answers it.

Independent review: use the same dated source packet in separate models/sessions where available; preserve raw reports and dissent. A fresh session is not proof of another model. Record same-author reviews honestly; majority vote cannot certify chemical safety.
