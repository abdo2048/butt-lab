# INERIS Dangerous-Waste Classification (mandatory safety benchmark)

French hazard authorities classify raw cigarette butts as dangerous waste
(HP6 acutely toxic, HP14 ecotoxic). Handling at scale carries regulatory
requirements (traceability, approved transport/disposal).

## Use in this lab
Every spec must include: input handling protocol, all waste streams and
their disposal route, and whether the jurisdiction requires waste permits.
A spec whose toxic output stream has no disposal route is incomplete.
