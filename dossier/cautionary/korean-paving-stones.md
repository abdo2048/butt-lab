# Korean Paving-Stone Failure (mandatory red-team benchmark)

Between 2021-2023 several South Korean municipalities recycled collected
butts into urban paving stones (acetate encapsulated, high-temperature heat
treatment). Chemical analysis found carcinogenic substances in the finished
product anyway; programs were discontinued. Reviewers concluded no currently
available technology guarantees complete removal of toxic components from
used filters, and butts should be treated as toxic waste.

[VERIFIED-SOURCE: Tobacco Control (BMJ), tc-2026-060135, 2026;
generationsanstabac.org/en/actualites/coree-du-sud-...]

## Use in this lab
Every proposed method MUST answer: would the Korean paving-stone test find
carcinogens in our output? Any spec without a toxin-removal mechanism that
survives this question fails phase 3.
