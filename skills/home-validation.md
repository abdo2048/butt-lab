# Skill: Home Validation Protocol

Design experiments the human operator can run cheaply to test spec claims:

TIER 1 — anyone:
- Mass balance: weigh before/after every step; report losses per stream
- Odor panel: sealed jar test, 24h, fresh nose, before/after each stage
- UV fluorescence: tar fluoresces under 365 nm UV lamp (~$10); compare
  fiber swatches before/after — crude PAH removal proxy
- Nicotine strips: cheap cotinine/nicotine test strips on rinse water
- Water contact test: soak fiber, test water for odor/color leaching

TIER 2 — maker:
- Small batch replication at reduced pressure/temperature with logging
- Acetone dissolution test: does recovered CA dissolve like virgin tow?
  (qualitative polymer-quality proxy)

TIER 3 — lab (budget items):
- One sample per method to a university FTIR service (polymer identity,
  ~$50-150/sample)
- GC-MS on extract or leachate for PAHs/nicotine quantification
- ICP-OES for Cd/Pb/As if metal removal is claimed
- EN/ISO ecotoxicity leachate test where certification is claimed

RULE: every experiment must state what result would DISPROVE the claim,
not just confirm it. Pass criteria are written before the experiment runs.
SAFETY: gloves, ventilation, no nicotine-skin contact, all liquids to
hazardous waste. Never exceed 10 bar without certified equipment.
